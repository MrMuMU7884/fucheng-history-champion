# 历史百万富翁 — 华小六年级

打开 `index.html` 即可使用（无需安装任何软件或网络）。学生端已全面中文化；人名、地名和马来西亚官方术语采用华文常用译名。

## 安装为应用

将文件夹放到网站服务器或 GitHub Pages 后，用 Chrome／Edge 打开网址，选择浏览器菜单中的“安装应用”或“安装到主屏幕”。安装后会以《辅成·历史学霸》独立应用方式开启，也可离线使用。

操作：

- 学生点击 A–D 答案。
- 老师按空白键（或点击黄色按钮）才显示正确答案与评语。
- 再按空白键进入下一题。
- 右下角“重新开始（随机排列）”会重新随机排列全部 200 题。

题库说明：

- Unit 1–10 对应 KSSR Semakan 2017 Sejarah Tahun 6 的官方主题。
- KSSR Tahun 6 官方课程实际上只有 10 个单元。为了配合 1–15 的课堂使用要求，Unit 11–15 被设计为只使用同一课程内容的考前复习题组，绝不混入其他年级内容。
- 每题四个答案皆为同一类别或和题干直接相关；学生选择后不立即判分，方便老师掌控课堂节奏。
